# 8拳减肥法

一个可添加到 iPhone 主屏幕的静态 PWA。每天固定 8 拳：

- 低热量：1 拳，黄瓜、番茄、蔬菜沙拉等。
- 蛋白质：3 拳，鸡蛋、鸡胸、鱼虾、豆腐等。
- 碳水：3 拳，米饭、面、红薯、玉米等。
- 零食：最多 1 拳，单独记录，不计入碳水进度。
- 水果：1 拳，苹果、橙子、莓果等。

## 功能

- 今日打卡：录入食物名称、类别和拳头数。
- 饮食计划：提前写好一天 8 拳吃什么，逐项打卡后自动进入今日记录。
- 分类进度：同时看总 8 拳和每类额度是否超出。
- 记录统计：粗略估算今日热量、累计拳头、日均拳头和最近记录。

数据只保存在当前浏览器 `localStorage`，没有账号、服务器或第三方接口。
